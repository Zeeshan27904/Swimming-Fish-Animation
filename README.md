# 🐠 Realistic Swimming Fish Animation

This project creates a beautiful, animated underwater scene using pure HTML, CSS, and JavaScript. It simulates swimming fish with dynamic tail and body movements, rising bubbles, and swaying underwater plants for a relaxing ocean environment.

---

## 🌟 Project Highlights

- Multiple animated fish swimming across the screen  
- Realistic tail flick and body sway for each fish  
- Soft gradient ocean background  
- Floating bubbles that rise from the ocean floor  
- Sea plants swaying gently like underwater vegetation  
- Fish are dynamically created using JavaScript

---

## 📁 Files Overview

- `index.html` → Structure of the page and elements like fish, bubbles, and plants  
- `style.css` → Visual styling and animations using keyframes  
- `script.js` → Adds fish elements to the DOM and controls dynamic animation behavior  

---

## 🎨 Animations Used

- **Fish swimming** – Moves from left to right and flips direction  
- **Tail flick** – Alternates rotation to simulate tail movement  
- **Body wave** – Subtle rotation of the fish body  
- **Bubble float** – Bubbles scale and fade as they rise upward  
- **Plant sway** – Sea plants gently rotate for underwater realism

---

## 🔧 Customization Ideas

- Add coral reefs, pebbles, or a diver character

## 📚 Concepts Used

- CSS variables for size, position, timing
- `@keyframes` animations
- CSS `transform`, `rotate`, `translate`, `scale`
- DOM manipulation with JavaScript
- Responsive and layered layout using `z-index`
